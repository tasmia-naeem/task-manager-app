# TaskFlow - Task Management System

A lightweight and responsive task management application developed with FastAPI and Jinja2.

The app allows users to create, manage and track daily tasks efficiently with a clean UI and dark/light theme support.

### Key Features
- Task CRUD operations (Create, Read, Update, Delete)
- Status management: Pending / Completed
- Task filtering and dashboard analytics
- Input validation and error handling
- Modern responsive UI with theme toggle

### Tech Stack
Backend: FastAPI, Python
Frontend: Jinja2, HTML5, CSS3, JavaScript
Data Storage: In-Memory (Can be extended to database)

python3 -m uvicorn main:app --reload
